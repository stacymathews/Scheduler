Travel Fairness Tracker
This page tracks how many days each technician has been assigned to work outside their home base. A travel day is counted each time a technician is scheduled to a community whose hub city differs from their home base city (set in Configuration). The Days Away column is a raw count — no thresholds or warnings are applied at this stage. The Load bar shows each person's days relative to the highest count in the current view. The vs avg column shows how many days above or below the team average each person sits — informational only, to help you spot imbalances visually. Future versions will allow you to set travel caps and trigger alerts.
